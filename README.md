# Data_Engineering_KasiMart
## 📌 Project Overview

This project explores the use of **Snowflake, a cloud-based data platform**, to store, transform, and analyse retail data for a fictional business called **Kasi Mart**. The project focuses on building a simple cloud data environment, loading structured CSV datasets into Snowflake, joining relational tables, and using SQL to generate business insights around customers, products, orders, and revenue.

---

## Project Objectives

The project required me to:

1. Create a database and schema in Snowflake.
2. Load customer, product, and order CSV datasets into Snowflake tables.
3. Apply appropriate data types to the columns.
4. Validate the data loads using record counts.
5. Use SQL joins to combine information from multiple tables.
6. Calculate revenue at order-line level.
7. Analyse revenue by customer and product category.
8. Identify the top 5 customers based on total spending.
9. Document the SQL queries and explain the business value of each analysis.

---

## 🛠️ Technologies Used

- **Snowflake** – Cloud data warehouse and SQL analysis
- **SQL** – Data querying, joins, aggregation, and calculations
- **Git & GitHub** – Version control and project documentation

## Dataset

The project uses three main datasets:

### Customers

Contains information about Kasi Mart customers.

### Products

Contains information about products sold by Kasi Mart.

### Orders

Contains customer purchase transactions.
